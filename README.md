# PUBG 枪械弹道下坠计算器

立即使用：**https://wineink.github.io/pubg-bullet-drop-calculator/**

完全离线的 PUBG（Steam 版）弹道下坠手动计算器。打开网页即用，不读取游戏内存 / 画面，不接入或抓取任何第三方软件。

## 功能

- 12 把栓狙 / 连狙：AWM、M24、Kar98k、Mosin、Lynx、Mini14、SKS、SLR、Mk14、Mk12、Dragunov、VSS
- 倍镜：4x（箭头 / 十字 / 圆圈三形态分划切换）、复合镜（复用 8x 高倍分划）、6x、8x（6x/8x 支持可调归零）
- **真实游戏分划**：4x 三形态、6x、8x 均使用游戏内截图抠出的真实分划（透明 PNG 内联），与游戏画面一致，红点按弹道结果实时叠加在分划刻度上
- 距离快捷按钮 100–450m，或直接粘贴雷神迫击炮工具测得的距离
- 「直接抬枪」与「归零后」两种视角模式
- 静止 / 行走 / 奔跑目标的横向提前量（mil 与身位）
- 实时计算子弹下坠量、飞行时间、抬枪 mil，并绘制下坠曲线图

## 数据口径

初速采用官方 / 社区一致值；下坠量与 mil 读数来自对局遥测数据（2026 年 8–9 月窗口，按 ½gt² 反推，g=9.8），0–600m 经单调三次插值，600m 以上为模型外推；遥测存在采样波动。抬枪量按「相对 100m 归零」计算（milAt(R) = 遥测 mil(R) − mil(100)）。

## 分划素材

分划素材来自游戏内截图抠图（透明背景 PNG），保留真实分划与黑色描边圆：

- `瞄准镜_带黑圈/`：真实分划 + 细黑线条圆
- `瞄准镜_纯分划/`：仅真实分划（无圆框）

覆盖：3x、4x（箭头 / 十字 / 圆圈）、6x、8x、15x。页面当前启用 4x 三形态、6x、8x（复合镜复用 8x 高倍分划）。

## 使用边界

本工具为完全离线的手动计算器：不读取游戏内存 / 画面，不接入或抓取雷神等第三方软件，距离需手动输入或粘贴。实战请以游戏内训练场实测为准。
